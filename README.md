# C# Projects

I've been learning C# since September 2025. This repository is where I keep some of the projects I've worked on along the way — not everything I make, just the ones that feel like a meaningful step forward.

The main purpose of this repo is to keep track of my progress over time: how my code changes, what I struggle with, and what gets better as I learn. These projects aren't meant to be production-ready, and some of them have known bugs or things I'd still like to improve. I'm keeping those things visible because they're part of the learning process.

Each project has its own README with a short description, instructions on how to run it, and notes about things I would improve or fix.

## Projects

- **RPN Calculator**:  converts and evaluates infix expressions using the Shunting-yard algorithm

- **Word Search Game**:  places words on a grid and lets you search for them
  
- **Tower of Hanoi**:  a console version of the classic puzzle
  
- **Tic-Tac-Toe**:  a console game against a simple bot
  
- **Speed Gate Data Processing**:  processes vehicle timestamps, calculates speeds, and generates a fine list
  
- **More to come**:  I'll keep adding projects as I continue learning and progressing through school

## Why

Mostly, I want to have a record of my own progress. It's also a way for anyone looking at my work — whether that's for school, internships, or something else in the future — to see where I started and how my projects develop over time.
