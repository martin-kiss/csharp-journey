# C# Projects

I've been learning C# since September 2025. This repo is where I'm uploading some of the more significant projects along the way — not everything I write, just the ones that mark some kind of progress.

The goal here is mostly to track how things change over time: how I structure code, what I get wrong, and what gets better. So don't expect polished, production-ready stuff — some of these have known bugs or missing features, and I'd rather leave that visible than pretend otherwise.

Each project has its own README with more detail and notes on what I'd still want to improve.

## Projects

- **RPN Calculator**: infix-to-RPN conversion and evaluation using a stack
  
- **Word Search Game**: places words on a grid and lets you guess them
  
- **Tower of Hanoi**: the classic puzzle, playable in the console
  
- **Tic-Tac-Toe**: console game against a bot
  
- **Speed Gate Data Processing**: reads timestamps, calculates speeds, and generates a fine list
  
- **Section Speed Control**: processes vehicle measurements and calculates section speeds
  
- **Vehicle Registry**: object-oriented vehicle and user management using LINQ

## Why

Mostly so I have a record of my own progress.

As the projects become more complex, I want this repository to show how my approach to C# and software development changes over time — from smaller console exercises to larger and more structured applications.

It is also something I can look back on when applying for university, internships, or future opportunities.
